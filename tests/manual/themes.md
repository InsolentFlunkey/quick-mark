# Theme native verification

Run these checks in a packaged or development desktop build on each supported platform.

1. Open Settings and choose Dark, Light, and QuickMark Classic in turn. Verify editor, preview, toolbar, tabs, dialogs, hover/pressed/focus/disabled states, warnings, errors, selections, and code blocks remain readable.
2. With two editor windows plus README, Markdown Cheat Sheet, and Markdown Examples open, change the theme. Verify every open window updates and a newly detached window starts with the selected theme.
3. Close every QuickMark window, relaunch, and verify the last selected theme is restored.
4. Verify native title bars and menus use the requested light/dark appearance where the platform permits; record any platform-rendered limitation rather than treating it as a web-theme failure.
5. Print or open print preview from each screen theme. Verify the result remains black text on white paper with readable tables, links, blockquotes, inline code, and fenced code.
6. At narrow window widths, verify Settings and all theme controls remain reachable by mouse and keyboard, with a visible focus indicator.
